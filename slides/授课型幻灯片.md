## 回顾：我们的第一个程序

**点灯 + delay**：`HAL_Delay(500)` 让 LED 每 500 ms 闪一次

- **CPU 被占住**：这 500 ms 里 CPU 只在“原地数圈”，想读传感器就塞不进去
- **时间不准**：多个 delay 叠加，实际周期越来越偏
- **不好扩展**：每加一个任务都要重算整套时序

---

## 阻塞式延时 vs 定时器中断

| 现在的做法：delay | 我们要的做法：定时器中断 |
|---|---|
| CPU 原地空转，500 ms 什么都干不了 | 硬件在后台自动数数，不占主循环 |
| 只能串行做一件事 | 到点自动触发回调 |
| 时间是“数循环”数出来的，主频一变就不准 | 时间是硬件给的，很“硬” |

**一句话**：把“等时间”这件事从 CPU 手里拿走，交给定时器。

---

## 定时器怎么工作

**计数链路**：时钟 72 MHz → PSC 分频 ÷72 → 1 MHz（1 µs 一格） → CNT 数到 999 → ARR 溢出

**中断链路**：更新事件 → NVIC → `TIM2_IRQHandler` → `HAL_TIM_PeriodElapsedCallback`

公式：`定时时间 = (PSC + 1) × (ARR + 1) ÷ 时钟频率 = 72 × 1000 ÷ 72 MHz = 1 ms`

---

## 三个数字，记住这一页就够

| 数字 | 含义 | 说明 |
|---|---|---|
| **72 MHz** | 定时器时钟源 | F103 的 TIM2 挂 APB1，倍频后 72 MHz |
| **999** | ARR 自动重装值 | 数到 999 溢出一次，即每 1000 个计数 |
| **1 ms** | 最终得到的周期 | 1 µs × 1000 = 1 ms，这就是“心跳” |

---

## 四个参数，一一对应

| 参数 | 作用 | 本例取值 | 怎么理解 |
|---|---|---|---|
| 时钟源 | 定时器的“心跳来源” | 72 MHz | TIM2 挂 APB1，倍频后 72 MHz |
| PSC 预分频 | 把时钟按比例变慢 | 71 | 分频系数 = PSC+1 = 72 → 1 MHz |
| ARR 自动重装 | 数到多少就溢出 | 999 | 溢出周期 = (ARR+1) × 1 µs = 1 ms |
| 更新中断 | 溢出时通知 CPU | 使能 | NVIC 里勾选 TIM2 global interrupt |

---

## CubeMX 里四步搞定

1. **选定时器**：Timers → TIM2，Clock Source 选 Internal Clock
2. **填参数**：Prescaler = 71，Counter Period = 999
3. **开中断**：NVIC 页勾选 TIM2 global interrupt
4. **生成代码**：Generate Code，再补两行启动代码

```c
HAL_TIM_Base_Start_IT(&htim2);   // 启动定时器并使能更新中断
```

---

## 代码其实只有两行

```c
volatile uint32_t tick = 0;        // 全局心跳计数器（volatile 不能省）

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM2) {
        tick++;                    // 每 1 ms 心跳 +1
    }
}
```

真正干活的只有 `tick++` 这一句。

---

## 主循环变得“非阻塞”

```c
while (1) {
    if (tick - last >= 500) {          // 每 500 ms 做一次
        last = tick;
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
    }
    // 还能顺便读传感器、跑巡线……
}
```

从“**等时间**”变成“**看时间**”——同一块板子，同时做两件事。

---

## 五个常见坑

1. 忘了 `HAL_TIM_Base_Start_IT` —— 中断永远不会来
2. 回调函数名写错 —— 必须是 `HAL_TIM_PeriodElapsedCallback`
3. `tick` 没加 `volatile` —— 开了优化会读到旧值
4. 在中断里干重活 —— 别放串口打印、delay、长循环
5. PSC / ARR 算错 —— 记住公式，填完看一眼显示的周期

---

## 课堂练习（5 分钟）

1. **基础**：把 LED 改成每 1 s 闪烁一次（**不许用 `HAL_Delay`**）
2. **进阶**：每 2 s 通过串口打印一次 `tick`，观察两个任务互不干扰
3. **挑战**：用 `tick` 量出“按键按了多久”
