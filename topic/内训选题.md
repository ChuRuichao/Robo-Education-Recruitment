# 内训选题方案：从点灯到定时器 —— STM32 嵌入式入门

> 4.5.1 内训选题 ｜ 储锐超 3260101888

## 一、选题理由

机协的内训需要一门"**零基础能上手、学完能做事**"的入门课。单片机的坑从来不在语法，而在**工具链**：环境装不上、编译报错看不懂、程序下载不进去，很多人就是卡在这一步放弃的。

所以这门课的目标很明确：**用 4 个课时，让完全没碰过单片机的同学能独立完成"建立工程 → 写代码 → 下载 → 调试"的全流程**，并顺手把后面 AnyCar 巡线小车、RM 电控所需的基础外设（GPIO / 定时器 / 串口 / 看门狗）打通。

## 二、课程基本信息

| 项目 | 内容 |
|---|---|
| 课程名称 | 《从点灯到定时器：STM32 嵌入式入门》 |
| 面向对象 | 零基础或刚接触嵌入式的同学（大一为主，不限年级） |
| 人数建议 | 12～20 人（两人一组，保证人手一套硬件） |
| 课时安排 | 4 课时 × 90 分钟（可分两周完成） |
| 前置基础 | 会一点点 C（变量、if、while、函数），认识"编译/下载"这两个词即可 |
| 教学形式 | 理论 40% + 动手 60%，每节课都有"能跑起来"的小目标 |

## 三、学习目标（学完之后能做什么）

1. 能独立安装并配置 **CubeMX + CMake + VS Code + arm-gcc + Ozone** 工具链；
2. 能看懂 CubeMX 生成的工程结构，知道代码该写在 `USER CODE` 区、业务代码放 `Tasks/`；
3. 会配置 GPIO（推挽输出、上拉输入）与外部中断，能写出按键消抖；
4. 理解**定时器中断**：会用 PSC / ARR 算出想要的周期，会写 `HAL_TIM_PeriodElapsedCallback`；
5. 会用串口打印调试信息（避免盲猜）；
6. 会配置 IWDG 看门狗，理解"程序跑飞会自己重启"；
7. 具备查**数据手册 / 参考手册**的习惯与基本能力。

## 四、课程内容与课时安排

### 第 1 课时：环境与第一个工程（90 min）

| 环节 | 内容 |
|---|---|
| 讲（25 min） | 单片机是什么、为什么选 STM32F103C8T6；工具链全景图（CubeMX → CMake → Ninja → arm-gcc → .elf → Ozone） |
| 练（55 min） | ① 装/配置工具链（提供离线包与镜像）② CubeMX 图形化配置 PC13 ③ 编译 + DAPLink 下载 ④ **点亮板载 LED** |
| 收（10 min） | 常见报错对照表；课后作业：把 LED 改成流水灯 |

### 第 2 课时：GPIO 与按键中断（90 min）

- 输入模式（上拉/下拉/浮空）、按键电路与**消抖**（软件延时 vs 定时器）
- 外部中断 EXTI 配置：边沿触发、中断回调 `HAL_GPIO_EXTI_Callback`
- 练：按键控制 LED 翻转；按键计数并按次数切换 LED 闪烁频率
- 小结：中断与轮询的区别（用"门铃 vs 反复开门看"比喻）

### 第 3 课时：定时器与串口（90 min）★ 本课重点

- 时钟树速览：72 MHz 从哪来；PSC / CNT / ARR 三兄弟的关系
- 公式：`定时时间 = (PSC+1)(ARR+1) / 时钟频率`；现场手算 1 ms
- 练：配置 TIM2 产生 **1 ms 中断**，全局 `volatile uint32_t tick` 累加，实现"不用 delay 的 LED 闪烁"
- 串口：`printf` 重定向 + 串口助手看输出（DAPLink 自带虚拟串口即可）
- 小结：如何在中断里"只做最少的事"

### 第 4 课时：看门狗与综合实践（90 min）

- IWDG 原理与配置（LSI 40 kHz、分频 64、Reload 1249 ≈ 2 s）
- 练：故意不喂狗 → 观察板子自己复位；再把喂狗放回中断里
- 综合：把前三次课的内容合成一个小工程（心跳 + 按键 + 串口打印 + 看门狗）
- 收尾：如何继续学（AnyCar 巡线小车 → PID → CAN 通信），以及资料在协会 GitHub 仓库怎么找

## 六、教学形式与实践环节

1. **边讲边练**：每讲一个概念立刻动手验证，"讲 10 分钟、练 15 分钟"交替；
2. **目标驱动**：每节课结束必须有一个"看得见的结果"（灯亮 / 按键响应 / 串口打印 / 板子复位）；
3. **分层任务卡**：基础题（照做）、进阶题（改参数）、挑战题（自己做），照顾不同进度；
4. **结对互助**：两人一组，一人查错一人操作，培养"排查问题"的习惯；
5. **错题本**：把当场遇到的报错和解决办法记进共享文档，沉淀成协会资料。

## 七、可能遇到的问题与解决办法

| 可能的问题 | 解决办法 |
|---|---|
| 工具链装不上、下载太慢 | 提前准备离线安装包 + 镜像；现场留 2 台"急救机"；实在不行两人一组共用一台 |
| 板子/下载器不识别 | 统一型号（F103C8T6 + DAPLink）；准备备用调试器；课上先统一讲一遍驱动安装 |
| 进度差异大 | 分层任务卡 + 课后作业；进度快的当"小助教" |
| 代码能编译但灯不亮 | 用"三步定位法"：① 引脚/电平配置对不对 ② 是否真的下载进去了 ③ 用 Ozone 看变量 |
| 安全与器材损耗 | 讲清"先接线后上电""防止电源短路"；每组配一根备用线；结束后统一断电归位 |
| 讲完就忘 | 全部资料（课件、代码、答疑记录）整理进 GitHub 仓库，供下一届复用 |

## 八、可评估的成果

- 课后问卷：能独立完成全流程的比例（目标 ≥ 80%）；
- 每人提交一份"键盘 LED 闪烁 + 串口打印 tick"的作业工程；
- 优秀作业（最先完成挑战题）可作为下届内训的示范代码。
